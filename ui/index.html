How it works

The selected benchmark compiles if needed, runs in its own folder, then the dashboard parses the latest output files and redraws the charts.

Interactive HPC dashboard

Run serial, OpenMP, MPI, or hybrid and inspect the results instantly.

This dashboard is designed for macOS and WSL/Linux workflows. Select a target and it will execute the right command path for the host environment, then render a heatmap and performance curves from the latest outputs.

Mode guide
  • Serial: No runtime settings (single process, single thread)
  • OpenMP: Set Threads and Schedule, then run
  • MPI: Set MPI processes, then run
  • Hybrid: Set MPI processes and OMP threads per process, then run
